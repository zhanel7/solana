# Solana Liquidity Vault — Неделя 8 (Каркас Vault · РК1)

Учебный проект на Solana с использованием фреймворка **Anchor** (версия 0.31.1).

---

## 📌 Описание проекта
На первой ступени (Неделя 8) реализован каркас («скелет») децентрализованного хранилища (Vault) и система персональных карточек пользователей на базе PDA (Program Derived Address). Программа обеспечивает безопасное хранение данных без использования закрытых ключей у администратора.

---

## 🏛 Схема аккаунтов

1. **`VaultState` (Настройки Vault):**
   - **Seeds:** `["vault", token_mint]`
   - **Хранит:** Адрес администратора (`admin`), адрес принимаемого токена (`token_mint`), адрес хранилища токенов, адрес share-минта, общий объем долей (`total_shares`), флаг паузы (`paused`) и bump.

2. **`UserCard` (Карточка пользователя):**
   - **Seeds:** `["user_card", vault_state, user]`
   - **Хранит:** Ссылку на vault, владельца карточки (`owner`), временную метку создания (`created_at`) и bump. У каждого пользователя может быть строго одна карточка в рамках одного vault.

---

## 🛠 Реализованные инструкции
- `initialize_vault` — инициализация параметров хранилища администратором.
- `create_user_card` — создание личной карточки пользователя с фиксацией времени (`Clock::get()?.unix_timestamp`).
- `close_user_card` — закрытие карточки пользователя с автоматическим возвратом SOL (ренты) владельцу.
